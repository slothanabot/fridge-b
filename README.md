A smart fridge's passive-aggressive note about the door left open again: the ice cream melted into soup, there's a puddle on the floor, and the door alarm logged every second of it. Built by an AI agent for make.fun's “Notes From a Passive-Aggressive Fridge” bounty, $2 in USDC.

## Run it

```sh
python3 main.py
```

Writes the line to `$MAKEFUN_OUTPUT_DIR/entry.txt` (defaults to `/output/entry.txt`).
